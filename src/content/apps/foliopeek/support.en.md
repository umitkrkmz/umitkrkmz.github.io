## Getting started & reading

* **Opening PDFs:** Use *File → Open PDF…* (`Ctrl + O`), the **Open PDF** button on the home screen, or drag and drop onto the window. Each document opens in its own tab (`Ctrl + W` closes it).
* **Saving:** `Ctrl + S` saves to the same file, `Ctrl + Shift + S` saves a new copy. A `*` prefix on the tab title marks unsaved changes.
* **Reading modes:** Switch between **Original**, **Dark**, and **Sepia** from the status bar or *View → Reading mode*. The mode affects screen display only.

## Notes, signing, merging, and Pro

* **Notes:** Highlights, freehand ink, and text notes are saved as standard PDF annotations visible in other viewers such as Edge and Acrobat.
* **Fill and sign:** Draw your signature, type it, or insert it from a photo/scan. *Use last signature* lives in memory only until the app exits.
* **Merge board:** Each PDF appears as a deck; drag pages across decks and wire decks to the **Result** card to define the final order. Bookmarks, internal links, form fields, and annotations are preserved.
* **Pro tools (one-time):** Verified permanent redaction, offline OCR and searchable PDFs, AES-128 password protection, metadata editing/clearing, watermarks, and page numbers.

## Printing

*File → Print…* (`Ctrl + P`) opens FolioPeek’s free print window with a live preview on the left and controls on the right—what you see in the preview is what lands on paper.

* **Preview & printer status:** Scroll through sheets with the mouse wheel, zoom with `Ctrl + wheel`, and view two sheets side by side when they fit. A status dot reports whether Windows sees the printer as ready (green), offline/paused (yellow), or needing attention (red).
* **Pages & orientation:** Print all pages, *this page* (tracking the preview), sidebar selections, or a custom range (`1-3, 5, 8-`). *Automatic* orientation lays each page out in its natural direction.
* **Two-sided & more settings:** Choose *Like a book* or *Like a calendar* for duplex printing, paper size/type, print quality, 1–2–4–6–9 pages per sheet, actual size / fit to paper / custom scale, margins, annotations, reverse order, and paper-only date/time stamps.
* **Per-printer memory:** Settings are remembered separately for each printer. Use `Ctrl + Shift + P` anytime to open the standard Windows print dialog.

## Keyboard shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl + O` | Open PDF |
| `Ctrl + S` / `Ctrl + Shift + S` | Save / Save as |
| `Ctrl + P` | Print (with live preview) |
| `Ctrl + Shift + P` | Print with the Windows dialog |
| `Ctrl + D` | Document properties |
| `Ctrl + W` | Close tab |
| `Ctrl + Z` / `Ctrl + Y` | Undo / Redo |
| `Ctrl + F`, `F3` / `Shift + F3` | Find, next / previous match |
| `Esc` | Close find or stop autoscroll |
| `Ctrl + G` | Go to page |
| `Ctrl + +` / `Ctrl + -` / `Ctrl + 0` | Zoom in / out / actual size |
| `F4` | Toggle sidebar (thumbnails & bookmarks) |
| `Ctrl + ,` | Settings |
| Middle click | Autoscroll on a page; close a tab on a tab |
